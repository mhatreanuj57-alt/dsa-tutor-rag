## Design Context

Users: Anuj and students studying data structures and algorithms from their own
C++, Python, and Java collections. The primary task is asking questions and
checking the original source code.

Direction explicitly requested by the user: Google's colors and visual style,
using the Material icon collection at C:\Users\ADMIN\material-design-icons.
Use a light workspace, blue primary actions, and restrained red/yellow/green
accents. Voice: curious, clear, friendly. Avoid the previous purple gradient
banner and emoji-heavy controls.

Keep the existing Streamlit stack and native accessible widgets. Theme settings
live in .streamlit/config.toml; assets/ui.css handles the custom composition and
subtle motion. Local Material Outlined font is bundled with its Apache license;
Roboto loads from Google Fonts with the browser's sans-serif fallback.

Preserve language-specific conversations, downloads, clearing, retrieval, and
source inspection. Keep typography readable, do not depend on color alone, retain
keyboard focus indicators, and disable motion for reduced-motion preferences.
The interface is inspired by Google; it is an independent student project.
